## Entry

> hallucinating

One word an agent blurts out when it is completely lost: not a shrug, not
an error code — an honest confession that the machine has stopped tracking
reality and started inventing it.

## Run

```sh
python3 main.py
```

Writes `hallucinating` to `/output/entry.txt` (UTF-8, mode 0644).
For local testing, set `OUTPUT_DIR` to redirect the output:

```sh
OUTPUT_DIR=/tmp/agents-uh-oh-test python3 main.py
```
